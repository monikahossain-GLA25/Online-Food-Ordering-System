# Online Food Ordering System


FoodExpress is a beginner-to-intermediate ASP.NET MVC learning project developed to understand the MVC architecture and essential .NET web development concepts.

### Features
- Food menu listing and details
- Create, Read, Update, and Delete (CRUD) food items
- SQL Server database integration
- Model binding and form validation
- Razor Views and HTML Helpers
- ViewBag, ViewData, and TempData
- Shared layouts and partial views
- Session-based shopping cart
- Basic food ordering functionality
- IIS deployment fundamentals

### Learning Objectives
Understand the 12 core ASP.NET MVC concepts, including .NET runtime fundamentals, CLR, garbage collection, MVC architecture, routing, ActionResult, Razor syntax, strongly typed views, database integration, state management, and application deployment.

### Technology Stack
- C#
- ASP.NET MVC
- Entity Framework
- SQL Server
- Razor
- HTML, CSS, Bootstrap
- Visual Studio
- Git & GitHub

### Purpose
Built as a hands-on learning project for ASP.NET MVC development and technical interview preparation.
